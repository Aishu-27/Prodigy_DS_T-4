# 🚦 Task 4: Traffic Accident Data Analysis

## 📌 Objective

Analyze traffic accident data to identify patterns related to:
- Road condition
- Weather
- Time of day

Additionally, visualize:
- Accident hotspots (e.g., using heatmaps or location clustering)
- Contributing factors to accidents

## 🛠️ Tech Stack

- **Language**: Python 3.x
- **Environment**: VS Code
- **Libraries Used**:
  - `pandas` – Data handling
  - `matplotlib` & `seaborn` – Data visualization
  - `plotly` or `folium` – For interactive maps
  - `scikit-learn` – Clustering (optional for hotspot analysis)

## 📁 Dataset

The dataset should contain fields like:
- `Time` (or Hour of Day)
- `Weather_Condition`
- `Road_Condition`
- `Latitude`, `Longitude` (or location details)
- `Severity` or `Casualties`

## 📈 Visualizations

This project generates:
- **Time-based patterns** (e.g., accidents by hour of the day)
- **Weather & road condition impact** bar charts
- **Accident hotspots** using map visualizations (heatmaps or scatter maps)
